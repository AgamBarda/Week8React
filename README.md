## How to run React app

```bash
cd react-app
npm install
npm start

How to build React app

```bash
cd react-app
npm run build

How to serve React from Node
```bash
cd serve-react-node
npm install
node app.js
open http://localhost:3000

How to run JWT login
```bash
cd jwt-auth
npm install
node app.js
